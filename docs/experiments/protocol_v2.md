## B. 最终实验流程

### 0. 研究口径（不变）
- 主问题（RQ1）：相位条件平滑修复（P）与统一平滑修复（U）相比，能否降低合成遮挡下的二维肘角恢复误差。
- 主要终点：二维肘角 MAE。配对差 Δ = MAE_P − MAE_U，负值表示 P 更好。
- 结论只限于投影二维，不推到三维生物力学；允许报告零结果或负结果。

### 1. 输入数据
- **标注**：947 条的仲裁最终版，另外原样保留 A/B 原始标注。
- **manifest 字段**：`sample_id`、`origin`、`stroke_type`、`num_frames`、fps/PTS、分辨率、`usage`（是否 Pilot），能追溯时加 `rally_id`。
- **姿态**：`rtmpose_26_project_v1`，记录 checkpoint 哈希。按已核实的映射提取左右肩、肘、腕、髋。只用目标球员；坐标为原图像素；缺失帧按帧号补 null。
- **时间轴**：优先用 PTS；否则在核实恒定 fps 后用 frame/fps，并记录 `timing_source`。
- **S0 自动核查**：
  - 标注帧数、姿态帧数、N 三者一致；
  - 目标球员和击球类型均已确认；
  - f、c 非空且 f ≤ c；
  - 击球臂属于 left/right/both。
  - 每一步的排除数记入 Table 1。

### 2. 可见性类别（逐关节、逐帧，由 A/B 原始标注程序生成）
| 类别 | 规则 |
|---|---|
| `visible_agreed` | A、B 都标 visible |
| `occlusion_agreed` | A、B 都属于 occluded_self / occluded_other |
| `self_occlusion_agreed` | A、B 都标 occluded_self（`occlusion_agreed` 的子集） |
| 出画 / 模糊 / 不确定 | 各自单独保留，只做描述 |
| `disputed` | 其余所有情况 |

- **`ref_ok`** = `visible_agreed` + 姿态非空 + score ≥ 阈值 + 上臂、前臂投影长度 ≥ 阈值 × 躯干尺度。
- 两个阈值都由 Pilot 冻结，默认值分别为 0.3 和 0.2。论文中写成"为减少投影退化和数值不稳定而设的筛选条件"。
- **置信度 ROC**（E0）：正类为 `occlusion_agreed`，负类为 `visible_agreed`，预测量为低 score。`disputed` 帧剔除；姿态缺失帧单独计数。

### 3. 相位定义
- 取仲裁版记录中的 b、f、c、e：
  - P1 = [b, f−1]；如果 b 为空、truncated 或 not_distinct，P1 = [0, f−1]，并标注 `p1_truncated`；
  - P2 = [f, c]，允许 f = c；
  - P3 = [c+1, e]；如果 e 为空或片段 ends_early，P3 取到 N−1，并标注 `p3_truncated`。
- P1、P3 之外的帧记为 unknown，平滑倍率为 1。
- c 为空、只标了接触区间的片段，不进入 E1/E2，只做描述。
- 击球臂为 both 时，两臂分别分析，在片段内平均；另做一次去掉 both 片段的敏感性分析。

### 4. 队列与数据隔离
| 队列 | 定义 | 用途 | 禁止 |
|---|---|---|---|
| Pilot | 已有开发片段 | 冻结阈值、λ 范围，核对掩码支持数 | 不进入任何测试评价 |
| H | 在运行 E1 之前，从非 Pilot 的合格片段中分层抽取：目标 24 条（3 来源 × 4 类 × 2），最低 12 条，种子 `20260907-human-reference-v1` | 人工参考评价 | 在所有折中都不参与调参或训练 |
| S | 其余合格片段 | E1 主实验 | — |
| R | 击球臂肘或腕在动作窗口内存在 `occlusion_agreed` 区间：≥ 2 帧，两侧各有 ≥ 2 个可观测帧 | E3 | 不报告"准确度" |

- **LOSO**：3 个来源轮流留出，λ 和相位倍率只在训练来源内部通过内层验证选择。
- 同一回合或近重复的片段归入同一组。
- 用 Pilot 做过设计这一事实要在论文中披露。

### 5. 方法（输入、表示、掩码、求解器全部相同）
| ID | 方法 |
|---|---|
| B0 | Raw：缺失帧不输出，报告 N/A 和覆盖率 |
| B1 | Linear：逐坐标按时间插值，不外推 |
| B2 | PCHIP：逐坐标，时间严格递增，extrapolate=False |
| U | 最小化 ½Σ_obs w‖q−p‖² + λ/2 Σ ρ‖D²q‖²，D² 按非均匀时间间隔定义（协议 I 节） |
| **P** | 同 U，平滑倍率 a_φ：P2 = 1，unknown = 1，P1、P3 ∈ {0.5, 1, 2} |

- 表示方式与 Pilot 一致：原图像素坐标，时间单位为秒。
- 权重 w 由 score 映射，score 低于阈值的点当作缺失。
- 每个关节的可观测点少于 2 个时拒绝重建，记为失败。只评价内部缺口，不外推。
- 掩码只作用于腕，或肘加腕；肩在输入端保持可观测。
- **λ 网格**：以 Pilot 的最优值为中心，对数间隔，覆盖 ±2 个数量级，共 9 档。Pilot 结束后写死。
- **搜索预算**：U 有 9 个配置，P 有 9 × 9 = 81 个配置。另做一次"U 在测试折上选最优 λ（oracle）"的检查：如果 P 仍然优于这个最强的 U，就说明相位增益不是调参投入多造成的。
- **不做**：模板法（U-T/P-T）、SG、SmoothNet、S-Corruption。论文中列为局限或未来工作；因此摘要中"corrupted"一词在正文里只写成"missing"。

### 6. E1 主实验：合成遮挡
- **关节组合**：只遮腕；肘加腕。
- **长度（按帧，30 fps）**：2 帧（≈67 ms，代替不足 2 帧的 50 ms）、3 帧（100 ms）、6 帧（200 ms）。另设 9 帧（300 ms）作为压力条件，只放在以触球为中心的位置。最终档位由 Pilot 支持数核对后冻结。
- **位置**：
  - 随机窗口：中心在 [f−10, c+10] 内均匀抽取，种子 20260907/08/09；
  - 触球中心窗口：以 c 为中心。
- **准入**：掩码内所有帧都 `ref_ok`；两侧各有 ≥ 2 个可观测帧；不超出片段范围。
- **每个掩码的标签**：中心所在相位；是否完全落在该相位内；是否跨越触球帧。
- **汇总顺序**：掩码 → 条件内平均（条件 = 位置 × 长度 × 关节组合）→ 片段内对可用条件等权 → 来源内平均 → 三来源等权。
- **终点**：
  - 主要终点：掩码帧上的肘角 MAE（度）。
  - 次要终点：被遮关节的定位误差（除以躯干尺度）；触球 ±100 ms 窗口内的角速度峰值衰减和峰时偏差；覆盖率和失败率。
- **统计**：
  - 每个来源的 Δ、三来源等权平均、片段 Δ 的中位数和 IQR、P 更优片段的比例；
  - 来源内 cluster bootstrap 2000 次（种子 20260907）。区间只解释为"给定这三个来源条件下的不确定性"。
  - 分层结果只做描述。

### 7. E1-H 人工参考（必做）
- **流程**：先为 H 生成掩码，再生成点标帧清单：H 掩码并集，每侧加 1 个邻帧，再加触球 ±100 ms 窗口（用于角速度）。人力不够时，优先删掉触球窗口，保留掩码并集。
- **标注方式**：两人独立点击肩、肘、腕，隐藏骨架，看不清的点不猜；之后形成共识。
- **共识规则**：两人坐标差 ≤ 阈值时取均值；超过阈值时由第三人裁决。阈值按躯干尺度的比例预设。原始坐标全部保留。
- 只有单人标注的片段单独列出，不计入"双人共识"。
- **Table 2B 报告**：姿态相对人工的肘角误差（测量本底）；同一批掩码下，pose 参考与 human 参考的 MAE 和 Δ 并列；两位标注者之间的角度差。

### 8. E2 相位边界敏感性
- **需要重跑的输入**：P 的相位边界，依次换成
  1. 仲裁边界（主结果）；
  2. A 的边界；
  3. B 的边界；
  4. 仲裁边界整体平移 ±2 帧（同时给出毫秒数），要求顺序仍然有效；
  5. 只用 f、c 的定义；
  6. 错配：P1、P2、P3 的倍率循环互换。
- A 或 B 缺少边界、或边界顺序无效的片段，不进入对应那一组，数量要报告。
- 报告 MAE 和 Δ 的变化幅度，不能只看方向是否一致。

### 9. E3 真实遮挡（oracle-mask 场景）
- **含义**：已知人工标注的遮挡位置后做修复，不代表自动检测遮挡的表现。
- **做法**：R 队列中把 `occlusion_agreed` 帧设为缺失，与 Raw 姿态输出比较。
- **指标**：覆盖率；肢段长度相对可见帧中位数的偏离；肘角 > 30°/帧的跳变次数；区间边界处的速度连续性。这些都只是合理性指标，不能证明准确。
- **Fig 3**：只画骨架和曲线，不用视频截图。例子的选择规则事先写好。

### 10. E4 下游分类（轻量版，优先级最后）
- **特征**：只用击球臂，从整段片段提取：肘角序列和腕相对肩的轨迹（除以躯干尺度），重采样到 32 点后做统计摘要。不使用相位标签，避免循环论证。
- **分类器**：固定参数的随机森林；按 3 来源 LOSO。
- **输入**：Raw、Linear、U、P（`occlusion_agreed` 帧替换为修复值）。
- **报告**：Macro-F1、各类召回、各来源结果。结论不外推到运动学效度。
